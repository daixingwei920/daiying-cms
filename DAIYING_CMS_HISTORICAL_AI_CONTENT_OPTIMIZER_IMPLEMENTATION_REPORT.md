## Batch Safety

AI batch size is limited to 5 by default and capped at 10.

The workflow records per-item failures and does not publish body changes.

## Data Protection

Still enforced:

- existing manual `seo_title` is not overwritten on save
- existing `seo_description` is not overwritten on save
- existing `seo_keywords` is not overwritten on save
- existing `target_keywords` is not overwritten on save
- existing `canonical_url` is not overwritten on save
- live `blocks_json` is not overwritten by AI generation

AI suggestions are saved as proposals and pending review drafts only.
