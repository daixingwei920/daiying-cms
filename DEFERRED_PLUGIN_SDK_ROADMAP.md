# Deferred Plugin SDK Roadmap

Deferred from Foundation V1:

- `PluginContext::license()`: official commercial license service.
- Queue SDK expansion beyond existing handler registration.
- Outbound webhook delivery contract expansion.
- Recovery Mode plugin APIs.
- Dependency management.
- Developer CLI.
- Automated plugin validator.
- Commerce refund/cancellation/order-created events.
- Async event queue/retry semantics.
- PluginDataStore `latest()` / `getLatest()` helper.
- Plugin-owned structured table service for `api` plugins.

These are valid roadmap items, but they are not required for the first SDK Foundation candidate.
