# Mobile Layout Spec

Mobile layouts must be authored, not merely scaled down.

Checklist:

- Uses `100svh`/`100dvh` where full-screen hero behavior matters.
- Supports iPhone Safari safe-area insets.
- Does not place primary controls under browser bars.
- Maintains readable hero copy.
- Keeps content cards reachable without horizontal scrolling.
- Tests narrow viewport widths around 360px, 390px, 430px.
