# Asset Naming Spec

Use lowercase kebab-case:

- `hero-background.webp`
- `foreground-left.webp`
- `figure-primary.webp`
- `prop-lantern.webp`
- `effect-glow.webp`

Avoid:

- spaces
- uppercase extensions
- duplicate names with different casing
- unversioned temporary names such as `final-final.png`

Theme packages must declare SHA-256 for market files.
