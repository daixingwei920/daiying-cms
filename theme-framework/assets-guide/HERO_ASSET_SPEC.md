# Hero Asset Spec

## Required Sets

Prepare separate desktop and mobile-safe crops when the scene is image-heavy.

Recommended:

- `hero-background.webp`
- `environment.webp`
- `foreground.webp`
- Optional figure images
- Optional prop images
- Optional effect overlays

## Size Guidance

- Desktop hero background: 2400px wide or larger.
- Mobile hero background: 1200px tall or larger.
- Export WebP for photographic/painted assets.
- Export SVG only for simple vector symbols that do not include scripts.

## Safe Area

Avoid critical visual content at:

- top 10% on mobile
- bottom 14% on mobile
- left/right 6% on narrow screens

The hero should remain readable under `100svh` and `100dvh`.
