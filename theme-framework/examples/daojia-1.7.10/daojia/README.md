# 清静无为 · Daojia 1.7.10

Daiying CMS Theme API v1 主题。

核心：首页三清坛场、双层旋转太极、敬香烟雾、三清铃/法剑/八卦镜/符箓互动、宣纸文章区、列表页、搜索页、正文页、上一篇/下一篇、404 与移动端适配。

说明：主题中的法器、符箓与互动均为传统文化视觉展示，不宣称现实宗教或超自然功效。
