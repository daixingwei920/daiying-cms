# Immersive Culture V1

Reusable framework module for expressive Daiying CMS themes with a first-screen scene, layered assets, optional figures, content cards, and safe Theme API usage.

## Included

- Responsive hero stage structure
- Generic layer naming
- Generic prop system
- Transition module hooks
- Content URL and logo helper guidance
- Base list/content/error templates

## Not Included

- Final artwork
- Final brand/culture text
- Theme market metadata
- Production signing assets

## Usage

Copy this framework module into a new theme workspace, add assets, edit `config/theme.json`, then build the final theme package.
