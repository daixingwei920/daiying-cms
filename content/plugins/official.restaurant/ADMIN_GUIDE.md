# 餐厅后台使用说明（本地候选）

本说明对应餐厅外卖1.0.2后台改版；不会自动升级现有网站。Square/Clover仅开放测试环境，正式POS连接尚未开放。

进入「餐厅外卖 → 店面与营业」，按下面七组设置。每次修改后点「保存店面设置」，看到「保存成功」才表示已经保存。

1. **基本资料**：填餐馆名称、电话、地址和时区，选择顾客首次看到的语言。顾客自己切换语言后会保留自己的选择。
2. **营业时间**：勾选营业日，选择开始、结束时间。中午和晚上分开营业时点「增加一个时段」。休息日不勾选；暂停接单可以随时单独设置。午餐、晚餐、儿童餐仍可按顾客需求购买，不因这个时间表限购。
3. **自取与配送**：分别开启自取、配送、预约。配送费直接填3.50这样的金额；多个配送邮编用逗号分开。免费配送也要明确填写0。开启预约前先设置营业时间。
4. **税费与收款**：填写实际销售税率，选择配送费是否收税、餐馆国家和收款适用地区。保存不会修改旧订单金额。银行卡收款仍在已有支付设置里配置。
5. **门头与照片**：从媒体库复制照片地址，可预览门头；用电脑和手机的滑块分别调整招牌位置。点「添加照片」增加环境照，可以分别填写三语照片说明。
6. **三语介绍**：展开English、中文、Español，填写对应的餐馆名称、标题和介绍。没有翻译的内容不会自动编造。
7. **收银系统**：进入 Square / Clover 连接页，按登录、选择门店、核对菜品、发送并确认测试单、开启新订单接入的顺序设置。首次须由管理员开通品牌应用和网站任务服务。真实品牌账号与设备尚待验收，详见 `POS_INTEGRATION_GUIDE.md`。

「菜品与价格」可点击菜名编辑，填写分类或从已有分类建议中选择；可勾选推荐到首页，填写图片地址。原来的规格和其他设置会保留。加料仍点「加」，选择米饭、鸡肉、牛肉等并填写价格。顾客“不要葱”等要求仍写在每道菜备注里。

「打印机」选择人工看板或店内打印助手。打印助手需要先在店内电脑安装和配对；不是选中某个收银品牌就能自动连接它的打印机。

测试付款、真实收银机和真实打印机分别验收。取消订单不等于已经退款；退款仍由店家人工处理。
