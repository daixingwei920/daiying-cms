# Core 1.2.86 maintenance release

Owner authorized publication on 2026-10-18. Base: merged PR #51, commit
`30cc9f741ac4a420248a4d9fd617f91b04f76962`. Previous official stable: v1.2.85,
`d578a05dae9742d177167cc4665482cc80cc9ea7`.

## Included fixes

- PR #47: enable migration-free ordinary API market plugins while retaining
  trust checks for trusted PHP, reserved official identities and migrations.
- PR #46: registered Passkeys may complete sensitive admin reauthentication;
  validate administrator, purpose, CSRF, origin, user verification and signature.
  Keep password fallback and the existing short-lived authorization window.
- Tell administrators to enable a plugin before granting payment permission.
- Retain the four regenerated Core integrity hashes from the integration.

No database migration, plugin-ID exception, integrity bypass, image AI, Logo
plugin, production payment setting or refund change is included. Minimum source
version remains 1.2.80; PHP >= 8.3. Publication does not upgrade production sites.

## Evidence and boundaries

The merged runtime tree passed relevant PHP syntax, market enablement/trust
boundary regressions, Passkey rejection-path and existing-login regressions,
payment permission guards/decisions, and knowledge consistency checks. On an
isolated update-server checkout, synthetic cryptographically valid WebAuthn
assertions completed reauthentication and were denied on replay. Release Gate
V1 and Phase 0 passed for that integration tree. Physical-device biometrics were
not tested. Version preparation changes configuration and documentation only;
runtime Core hashes are unchanged from that tested tree.

Exact final-main build, official signing, pristine installation, native upgrade
and preparation-failure rollback, public API selection and download hashes must
be verified before publication. Their exact commit/hashes and actual outcomes
belong in the final publication record; integration evidence alone does not
claim that release or production acceptance passed. MySQL upgrade remains
unverified unless separately executed.

## Knowledge synchronization

V1 JSON, Markdown and USER-FACING projection are pinned to reviewed 1.2.86
source. Existing visibility gates remain intact. Product knowledge validation
checks source provenance only; runtime test results are recorded separately.
No production knowledge import, index rebuild or consumer application is
performed by this release procedure.
