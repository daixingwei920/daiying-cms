## 发布前必须确认

- 每次正式发布均真实测试 SQLite / MySQL 空库安装、完整迁移、管理员创建与登录、文章发布、媒体上传、主题/插件基础兼容、Core 完整性、签名和安装/更新包 parity。任何声明支持数据库的全新安装失败均阻止发布。
- 本轮实测 MySQL 8.0.46 / Linux PHP 8.3；适配层限制 MySQL >= 8.0.13。其他版本、MariaDB、生产 PHP 8.5 组合不能自动继承本轮 PASS，正式支持矩阵需审核。
- 当前更新包仍声明最低 1.2.52，而旧更新器读取当前完整包存在已知不兼容。不能宣称所有旧版本直接升级已验证；支持范围或说明修订须单独由 Owner 审批，本轮不降低最低版本、不制作过渡包。
- CommerceRepository 的 MySQL 参数修复属于独立插件交付；Core 更新包不会更新客户已安装的 Commerce。插件版本、签名、分发及客户更新流程另行审核。
- 官网主题 Keywords 问题与 Core 分开处理，生产未修复。Auto Publisher 保持 P1 PARTIAL，未部署。
- 合并审核、canonical preflight、官方签名、生产等效验证及正式发布审批仍须独立完成。
