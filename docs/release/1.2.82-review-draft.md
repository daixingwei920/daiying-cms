# Daiying CMS Core 1.2.82 发布说明

Owner 已授权合并、正式签名及发布。生产站点安装升级另行执行，不包含在本次发布操作中。

- 修复独立 Release 架构下的媒体实例根目录解析；保留实例隔离及完整性保护。
- 修复内容 PATCH 的分类、标签和非目标 Meta 保留，增加并发冲突检测与发布追踪。
- 保留已验证的 MySQL 历史迁移精确方言适配：49 份历史迁移及 checksum 不变，仅四项明确受限适配，不进行任意 SQL 替换。
- 安装完成审计仅在配置和完成锁成功后记录。管理员提交后发生完成锁故障，保留数据库配置和站点身份并阻断公开重装；改用负责人受限人工处理。
- 戴影小说、戴影视频主题及配套插件保持 RETIRED；历史迁移、订单、授权和客户资产保留。

## 发布前必须确认

- 每次正式发布均真实测试 SQLite / MySQL 空库安装、完整迁移、管理员创建与登录、文章发布、媒体上传、主题/插件基础兼容、Core 完整性、签名和安装/更新包 parity。任何声明支持数据库的全新安装失败均阻止发布。
- 本轮实测 MySQL 8.0.46 / Linux PHP 8.3；适配层限制 MySQL >= 8.0.13。其他版本、MariaDB、生产 PHP 8.5 组合不能自动继承本轮 PASS，正式支持矩阵需审核。
- Owner 已批准 1.2.82 仅支持 1.2.81 直接升级。低于 1.2.81 不领取或执行本次更新包；不承诺其他旧版本直接升级，不制作过渡包。历史迁移、数据、授权和版本记录继续保留。更新服务器须按 docs/release/1.2.82-upgrade-support.md 完成发布前分发核验。
- CommerceRepository 的 MySQL 参数修复属于独立插件交付；Core 更新包不会更新客户已安装的 Commerce。插件版本、签名、分发及客户更新流程另行审核。
- 官网主题 Keywords 问题与 Core 分开处理，生产未修复。Auto Publisher 保持 P1 PARTIAL，未部署。
- 正式发布仍须完成 canonical preflight、官方市场服务端签名及产物校验。
