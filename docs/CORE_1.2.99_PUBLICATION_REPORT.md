# Core 1.2.99 正式发布

Core 1.2.99 已发布到[GitHub Release](https://github.com/daixingwei920/daiying-cms/releases/tag/v1.2.99)和官方 stable 更新服务。不可变标签 `v1.2.99` 指向合并主线 `c794aec96976563ccc29bf1c3fd677fe62fe7eaf`；更新服务发布于 2026-11-15 21:48（纽约时间）。没有升级生产网站，也没有发布 AI 代运营、小说、影视或 CJ 插件。

## 本次内容与发布前技术债核对

- `ai.tool` 注册现在校验工具归属与插件 ID 一致，阻止不同插件接管已有工具 ID；声明该能力的插件可发送由 Core 标记来源的代运营巡查唤醒事件。没有新增迁移或插件能力；最低升级来源 Core 1.2.80，PHP 8.3 起。
- 发布前定向核对 Core、AI 代运营、小说、影视及可访问的 CJ 源码中的 AI 工具注册；现有可访问声明没有归属冲突。Core 1.2.99 未发现阻止单独发布的技术债。V2 插件的市场签名、真实 Dot/邮件和 CJ 协议接入仍属独立未完成工作，不能据此宣称 V2 整体已发布。
