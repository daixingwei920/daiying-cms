# 星舰后台与内容管理（隔离开发候选）

Owner认可星舰指挥舱概念图后授权实现。Clean `ui/admin-starship` 起于 main `8964902b11a07d6623037e14c01974c08ebe23e8` / Core1.2.95；本任务不升版本、不合并、不签名、不发布、不部署官网。

## 已实现

- 认证后的共享后台使用深蓝/青色静态主题，统一导航、表格、输入框、卡片、状态、焦点与确认提示；保持现有分组和折叠行为。登录和前台不加载此主题。
- 内容列表复用原有 adminCount/adminList 分页数据，保持默认50、上限100条；原创建、编辑、查看、预览、删除POST、CSRF、确认和权限控制保留。新增更新时间列使用已返回字段。
- 搜索、类型、状态筛选只处理当前页DOM，界面明确标注本页范围和真实匹配数量。未实现全站搜索/统计，不显示概念图中的虚构作者、分类或批量操作。
- 详情按钮按需开启单个原生dialog，只读取已渲染字段，不重复请求；使用textContent保留转义，链接复用原地址。支持焦点圈定、Escape关闭和焦点归还。无JS时原列表/编辑/预览等操作保留，增强控件不显示。
- 无新框架、字体下载、外部资产、轮询或后台查询；移除原顶部/编辑栏的磨砂模糊，静态配色和短交互过渡，支持减少动态效果偏好。资源版本已更新，清单只更新AdminController/View两个成员。
