# Core 1.2.102 正式发布

Core **1.2.102** 已发布到 [GitHub Release](https://github.com/daixingwei920/daiying-cms/releases/tag/v1.2.102) 和官方 stable 更新服务。不可变标签 `v1.2.102` 指向合并主线 `7004f868211df4e5643213a43c08b2b9dc0bb542`；官方更新时间为 **2026-11-21 06:10:57 UTC**。本次没有升级任何生产网站。

## 修改范围

- 蜘蛛统计新增真实来源证据：固定官方 HTTPS IP 段，或反向 DNS 后缀与正向 A/AAAA 回查。仅匹配证据的新请求标为已验证；混合、待处理、过期、失败、不支持及历史记录分别呈现。历史记录不补验，验证不保证搜索收录。
- HTTP 请求只使用有界本地缓存/私有加密任务，不执行外网核验；由现有分钟 CLI 调度执行。忽略访客转发头，私有连接地址不验证。代理/CDN 的真实 IP 恢复及 Cron 由站点管理员另行配置，本次未修改生产配置。
- 移除侧栏底部在滚动时遮挡菜单文字的装饰，保留已确认的字号和选中边框，无新框架、字体或动画循环。
- 新装包补齐随包 Commerce 基础版缺少的两个餐厅辅助接口，保留待支付状态保护、同值重试和 Core 可信账本绑定。Core 更新 ZIP 不覆盖已安装业务插件，本次未发布独立市场插件。
- 同时携带主线已合入的市场安装失败回滚维护。无新迁移或 Core 公开 API 变更；最低 Core 1.2.80 / PHP 8.3。

原主线和修复前完整测试均出现餐厅缺少 Commerce 方法的失败；经 Owner 追加授权后修复并完整复测。MySQL 临时测试包误包含站点配置、原生升级外层脚本未生成测试准备文件两项测试夹具错误也已保留并修正，未削弱安装器或改变冻结签名包。此前 1.2.101 签名准备保持未发布且不可变。
