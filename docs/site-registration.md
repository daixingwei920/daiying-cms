# 全站 ICP 备案号（1.2.85 候选）

在后台「平台 → 站点设置」（`/admin/settings`）的站点 URL 下方填写「ICP 备案号」，点击「保存站点设置」。填写真实备案文本，例如 `京ICP备12345678号-1`；没有备案号时留空。本设置只负责展示，不能代办备案或证明备案有效。

配置保存在 `config/app.php` 的 `site.icp_number`，不需要数据库迁移。切换主题仍保留。保存沿用管理员登录、POST、CSRF 校验和原生配置备份写入流程；限制为有效 UTF-8、120 字节以内，不接受 HTML 或控制字符。留空可清除，旧表单未提交该字段时保留原值。

Core 将备案号传入主题的公开上下文。对于含 `</body>` 的完整 HTML 主题，渲染时在页面底部居中显示备案号，并链接 `https://beian.miit.gov.cn/`。Core 更新不覆盖主题文件，因此已有完整页面主题也可直接使用；空设置不增加页脚。该展示用于由 Core 主题运行时渲染的页面，不承诺自动覆盖插件自行返回的页面、外部页面或 HTML 片段。

旧主题专属 `icp_text` 及其显示逻辑保持不变，不自动复制、删除或覆盖。如以前已在主题中填写备案文字，迁入全站设置后可手动清空旧主题中的重复文字。

主题可使用 `site_icp_number` 或 `$context->siteIcpNumber()` 读取纯文本。如需在自己的页脚区域放置完整链接，输出 `$context->siteIcpFooter()`；此 helper 带有 `data-cms-site-icp="1"` 标记，Core 不会再追加第二份。自行输出文本必须调用 `$context->e()` 转义。HTML 片段主题需主动使用 helper。

验收脚本：`php tests/site_icp_settings.php`，覆盖真实后台保存/回显、清空、认证与 CSRF、错误输入不落盘、默认/媒体/安全主题、主题切换、前台读取和输出转义。浏览器模拟视口不等于实体手机验收；隔离 SQLite 不等于生产站或 MySQL 验收。
