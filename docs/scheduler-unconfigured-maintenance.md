# 未配置搜索指标与停用插件残留任务修复

Google 搜索指标未配置时，原实现先构造必须有 URL 的请求，再由 Provider 判断连接状态，导致未开启 Google 集成也报 `Search metrics site URL is required.`；历史失败还会覆盖「未连接/未配置」状态。另一方面，插件生命周期退出 Enabled 后没有停用所属计划任务，留下缺失处理器的反复失败任务。

修复复用现有连接仓库、SchedulerService 和插件生命周期：先检查连接状态，在原有异常处理范围内对未连接/未配置直接返回明确状态；只有配置及凭据完整才启用自动同步。真实授权错误继续可重试，损坏凭据安全失败，不发送外部请求。插件退出 Enabled 时只停用属于该插件的任务，保留 payload、错误和运行历史，正常 boot 注册可重新启用。未知插件不会影响任务。

本次生产只做两项可逆维护：官网非活动1.2.81移入私有归档，小说网停用已禁用 AI 代运营插件的残留任务。升级前后配置、内容、支付数据及 Core 完整性保持；没有启用 AI、调用模型、发起支付或清空历史错误。SEO Core 补丁尚未部署，Google 搜索数据实际同步没有验收为通过。
