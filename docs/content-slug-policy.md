# 固定链接书名号兼容（CMS-DEBT-20261012-01）

Core 1.2.83 支持在文章、页面和分类的显式 slug 中保留 `《》`。留空时仍按标题自动生成字母、数字和连字符组成的简洁 slug。已有文章和重定向不自动迁移；文章 #75 的现有新网址及 301 无须撤销。

保存、编辑、公共读取及官方导入使用统一校验。显式输入仍会将普通空白/其他标点归一化为连字符；禁止路径分隔符、路径穿越、控制字符、查询/片段符及已编码的百分号输入，最长 191 字节。不要将 URL 的 `%E3%80%8A` 直接粘贴进 slug 字段；填写原始 `《`。

前端只解码一次路径段。链接、canonical、站点地图及新导入的 URL Mapping 对 slug 进行百分号编码，禁止双重解码绕过校验。官方导出/导入保留书名号；不改历史数据库迁移。

验证：`php tests/content_book_title_slug.php`。测试包含完整原生迁移、真实内容保存/读取、页面响应、XML 站点地图、原生导出/导入及安全负例；不是生产站升级或搜索引擎收录证明。
