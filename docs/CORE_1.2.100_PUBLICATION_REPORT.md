# Core 1.2.100 正式发布

Core 1.2.100 已发布到 [GitHub Release](https://github.com/daixingwei920/daiying-cms/releases/tag/v1.2.100) 和官方 stable 更新服务。不可变标签 `v1.2.100` 指向合并主线 `ff8ddf1a903835bb2bbede1b78cf70960e4e1d17`；更新服务发布时间为 2026-11-16 13:21:32 UTC。没有升级任何生产网站，也没有发布 AI 代运营、小说、影视或 CJ 插件。

## 内容与运维边界

- 新增 `php cli.php run-scheduled-tasks [limit]`，调用既有 Core 调度服务执行已登记的 Core 与已启用插件任务。新入口在启动插件前取得站点级非阻塞进程锁，避免慢速任务和下一分钟调度重叠。
- 目标站须由管理员以站点 OS 用户配置每分钟一次的 cron；Core 升级本身不创建系统定时任务。没有新迁移或公开插件 API，最低升级来源仍为 Core 1.2.80，最低 PHP 8.3。
- 这一 Core 发布补齐代运营 V2 的运行入口，但不代表 V2 插件整体已正式发布或真实 Dot 环境通过验收。
