# Core 1.2.95 正式发布

Owner要求修复验证成功后无法继续、返回丢失包路径的更新流程。Core1.2.95已发布到[GitHub Release](https://github.com/daixingwei920/daiying-cms/releases/tag/v1.2.95)及官方stable更新服务。PR89冻结源`8f97bda5b15beceb23b06f4f3c1cc38bbc387aa9`，不可变标签`v1.2.95`；官方发布时间UTC 2026-11-05T04:51:35+00:00。

## 修复与用法

验证包通过后，验证摘要首屏提供“继续执行更新”，自动携带原包路径和CSRF；手填`UPDATE CORE`后提交。点击“返回系统更新”时，验证和执行表单均恢复路径。验证失败、执行失败的返回入口同样保留路径。

执行仍重新验证签名、完整性和兼容性；管理员鉴权、CSRF、手填确认、恢复点和维护模式规则保留。没有新增迁移。本次只发布Core版本，未升级、冻结或修改官网、影视站、小说站。

旧安装仍先按其现有更新入口准备并执行1.2.95，升级成功后才具备新流程。旧版验证页若缺少继续入口，可复制验证时的服务器包路径，返回系统更新后粘贴到执行区域、填写确认；也可使用现有`/admin/update?prepared_package=<URL编码的服务器包路径>`恢复两个表单。
