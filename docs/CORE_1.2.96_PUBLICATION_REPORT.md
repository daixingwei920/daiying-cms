## 本次内容

- 蓝色主色、白色面板、浅灰背景合入现有单个admin.css，统一静态切角、顶部折线、导航、状态和面板层次，更新资源缓存版本。无额外配色文件、外部字体、框架、持续动画或新查询。
- 内容管理提供明确限定当前页的标题/Slug、类型和状态筛选；宽屏详情并排列于列表旁，窄屏采用原生模态抽屉，支持Escape和焦点归还。

- 其他页面沿用现有功能分组和表单。部分仍为原生长表单，独立插件专属页面未在Core样例中启用，不宣称已全部重排或验收。公共API和所有发布迁移不变。
