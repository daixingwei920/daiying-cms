# Core 1.2.103 正式发布

Core 1.2.103 已在 [GitHub Release](https://github.com/daixingwei920/daiying-cms/releases/tag/v1.2.103) 和官方稳定更新渠道发布。冻结标签 v1.2.103 指向合并提交 `5d9999e73cfe628b16f83a19b1a4c01be93fa33a`。

分钟调度任务可选择使用下一个 UTC 间隔边界。任务领取时同时检查到期时间和锁，避免旧扫描结果重复领取。其他任务保留原有完成时间间隔。没有新增数据库迁移，最低可升级版本仍为 Core 1.2.80，最低 PHP 为 8.3。

完整回归 262 个步骤通过，覆盖 PHP 8.3、8.5、SQLite 和隔离 MySQL。签名包 647 项一致性检查、两套 PHP 环境各 71 项从 1.2.102 原生升级和回滚重试，以及 16 项匿名下载检查通过。

- 原生更新包 SHA-256 `bfcd343070a455236b81c2f07ebe228f940c78451e49c462d66d35bb0a85b26e`
