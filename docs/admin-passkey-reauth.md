# 管理员 Passkey 重认证（隔离候选）

后台安全页已有 Passkey 注册和登录能力。本候选让已注册 Passkey 的管理员，在「敏感操作重认证」处选择设备的人脸、指纹或系统 PIN 完成验证；原有管理员密码方式保留。浏览器和设备决定显示哪种验证方式，CMS 不读取或保存生物识别数据。

使用前，管理员须在 HTTPS 站点的「后台安全」添加 Passkey。需要为插件授予 `payment.access` 等受短时重认证保护的权限时，先启用插件，再完成重认证，并在 10 分钟内返回插件详情执行授权。Passkey 重认证不能解决插件自身启用失败；某些独立敏感操作仍要求输入管理员密码。

服务端将 WebAuthn 挑战绑定当前管理员和 `reauth` 用途，要求用户验证标志、原站点来源、签名及 CSRF 校验。失败、过期和跨账户挑战不创建短时授权；无 Passkey 或设备不支持时使用密码。此文档描述隔离代码候选，不代表正式 Core 或生产站点已部署。
